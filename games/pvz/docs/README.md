# 植物大战僵尸 · 花园保卫战

入口 `/games/pvz/`，另有 `pc.html`、`mobile.html`。独立网页玩法复刻，不连接原作服务器或账号。

## 玩法

- 50 关，五个十关章节：阳光草坪、月夜庭院、泳池派对、迷雾后院、屋顶决战。
- 13 种植物随关卡解锁；经典阳光、费用和种子冷却，鼠标 / 触控选卡再选格，支持铲除。
- 向日葵、豌豆、坚果、樱桃、地雷、寒冰、双发、大嘴花、小喷菇、窝瓜、睡莲、花盆、卷心菜。
- 普通、路障、铁桶、橄榄球、读报和巨人僵尸；逐行行走与啃食，寒冰减速；每行一台一次性割草机。
- 夜晚天降阳光更少，小喷菇仅夜晚射击；泳池为 6 行，中间 2 条水道需要睡莲；屋顶先放花盆，前三列已备好。
- P 暂停、F 全屏、S 铲子、1–9 选卡、Esc 取消选卡 / 暂停。可切换自动收阳光；切后台自动暂停。
- 手机横握游玩，竖握采用旋转横屏布局，触控坐标经过逆变换；全屏 API 不可用时保留沉浸布局，iOS 可添加主屏幕。

## 实现和素材

`engine.mjs` 为确定性纯逻辑，`render.mjs` 绘制场景与弹丸，原版角色使用本地 DOM GIF 播放动画，而非把动画当静图绘制。`art.mjs` 为额外植物 SVG，`profile.mjs` 为独立有界存档键 `fish-pvz-v1`。

部分原版图像来自公开网页项目的素材镜像；原作品权利与镜像项目许可分开记录。音乐为公开 CC0 花园主题曲，非原声。完整原文件映射、SHA256 及许可证见 [ASSETS.md](ASSETS.md) 与 [SOURCE-GPL-3.0.md](SOURCE-GPL-3.0.md)。

## 验证和发布

```powershell
npx vitest run games/pvz/tests
npm run check
npm run build -- --games pvz
pwsh -File scripts/deploy.ps1 -Games pvz -SkipInstall
```

50 关采用只调用正常收阳光 / 种植 / 铲除 API 的可重复玩家策略验证，未注入免费资源或跳过敌人。独立发布继承并校验所有未选择游戏。共享层只新增 GIF 资源白名单、预览 MIME 与 Nginx MIME，不改旧游戏。
