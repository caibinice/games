# APK 本地协议后台

仅用于本机测试参考 APK。Python 提供 HTTP 代理和角色控制接口，复用 `../local-protocol/` 中已验证的 Node 二进制协议编解码。不是另一套联网游戏服务器，也不转发到原游戏服务。

## 启动

要求 Python 3.10+、Node.js，以及从当前测试 APK 提取的版本响应和 `PlatformInfo`。密钥只从本机文件读取，不复制到源码、网页或文档。

在 `E:\codes\games` 执行，替换两个输入文件路径：

```powershell
$env:PYTHONPYCACHEPREFIX = 'E:\Documents\AI\codex\tmp\zombie-native-fixture\pycache'
python games\zombie\tools\local-protocol-python\server.py `
  --version-file E:\path\version-response.body `
  --platform-info E:\path\PlatformInfo.bytes `
  --data-dir E:\Documents\AI\codex\tmp\zombie-native-fixture
```

四个端口均只绑定 `127.0.0.1`：HTTP `53173`、客户端 TCP `53174`、内部协议 HTTP `53175`、控制接口 `53176`。可分别使用 `--http-port`、`--tcp-port`、`--worker-http-port`、`--admin-port` 调整，四者必须不同。区服响应会使用所选 TCP 端口。

测试模拟器采用独立实例；先记录其原代理和 reverse 映射，再添加：

```powershell
$adb = 'E:\Programs\MuMuPlayer12\shell\adb.exe'
& $adb -s 127.0.0.1:16416 reverse tcp:53173 tcp:53173
& $adb -s 127.0.0.1:16416 reverse tcp:53174 tcp:53174
& $adb -s 127.0.0.1:16416 shell settings put global http_proxy 127.0.0.1:53173
```

仅进入本地合成游客角色。测试结束移除本次添加的 reverse，并恢复记录的代理。不要覆盖其他实例或已有 reverse。

## 调整合成角色

```powershell
$ctl = 'games\zombie\tools\local-protocol-python\control.py'
python $ctl status
python $ctl set --level 30 --gold 500000 --diamonds 12345 --energy 500 `
  --attack 250 --max-hp 5000 --fight 1000 --reagent 99 `
  --gems 900410207,900010107 --forms 82001,82004 --equipped-form 82001 `
  --outfits 81001 --equipped-outfit 81001 --mercs 101 --active-merc 101
python $ctl set --core-level 1 --cores 1000:14,2000:10 --goods 61001:10000,50001:10000
python $ctl profile
python $ctl shutdown
```

自定义数据目录/端口时，在子命令前加 `--data-dir PATH --admin-port PORT`。修改后重登 APK；仅修改金币等不会清除洗练结果，修改 `gems` 或 `reagent` 会重建测试背包基线。`reset` 清空控制覆盖值，不删除已创建角色。`shutdown` 会关闭监听、终止本次 Node 子进程并删除 token/lock；优先使用它结束测试。收到 `stopping` 后先确认该目录的 `fixture.lock` 已消失，再启动下一次服务，避免关闭与重启抢锁。

角色数据保存在 E 盘数据目录；控制令牌随机生成并由工具自动读取。不要提交 `control.token`、`profile.json`、`role-state.json` 或诊断日志。若强制关机遗留 `fixture.lock`，先核对其中 PID 和命令行，再清理已停止进程留下的锁。

## 限时健康检查

```powershell
python games\zombie\tools\local-protocol-python\monitor.py --seconds 0
python games\zombie\tools\local-protocol-python\monitor.py --seconds 12 --interval 2
```

自定义目录/控制端口时同样增加 `--data-dir PATH --admin-port PORT`。单次 HTTP 超时 2 秒，监测最长 60 秒；服务失联立即结束。输出包含连接数、包计数、最近指令、最近收包间隔和未实现指令，不打印控制令牌。进程存在与协议实际响应分别检查；客户端未连接会显示 `connections: 0`，这本身不是服务卡死。

每批诊断不超过 30 秒；启动服务使用隐藏后台进程并记录 PID，不让常驻服务占着命令执行条。若测试超时，要同时结束该次测试的子进程，再按文件分组重试。
