# 源特效材质与序列修正

版本：`20261030-native-fx12`。本批以 APK 原始材质、ParticleSystem 和 LineRenderer 为依据，不使用截图作为特效素材。

## 修正内容

- 旋风主体：按原始 4×3 序列、5 秒生命周期、6 次循环取帧，改掉此前整段只播放一次的问题。
- 制导激光：原来拉伸的是吸收粒子贴图；现提取 `eff_zhidaojiguang_line/line/Line1` 的实际光束纹理，使用源橙色顶点颜色、横向纹理及 U 方向滚动速度。
- 电磁穿刺：使用基础命中特效 `eff_diancichuanci_hit/scale/kqd (1)` 的颜色、0.25 秒粒子寿命和透明度曲线，不混用另一分支材质。
- 高能射线、旋风分层、跃迁电子：接入对应源材质与粒子/线段颜色；跃迁电子保持独立 LineRenderer 的 1×6、12 fps 采样，不用共享粒子的 6×1 参数覆盖它。
- 在主页初始化时后台预热 24 张贴图；渲染器复用同一个加载任务，不再等第一次进入战斗才开始请求全部特效。
- 颜色缓冲按贴图复用，不按每帧创建画布；视觉采样不调用战斗随机数，不更改伤害规则。
