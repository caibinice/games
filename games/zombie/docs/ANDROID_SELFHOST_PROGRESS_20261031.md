## 仍待完成

1. **清理参考 APK 的第三方注入。** 当前仍有推广弹窗和悬浮入口；登录、切换界面时会再次出现。手机包应去掉这些入口及对应外部通信，而不是让用户点击第三方注册或后台。
2. **补齐并核对 SDK 初始接口。** `/login/fcm_config.php`、`/login/login_config.php` 和 `/notice/get_policy.php` 本轮仍返回明确的未实现状态；当前流程存在客户端回退行为，尚未补齐字段。
3. **核对原生协议缺口。** 本轮主页初始化出现未实现命令 `11810`，没有阻止本次主页展示。继续定位其实际结构，不返回通用成功掩盖缺口。
4. **扩展可玩内容。** 当前后台仅开放并验证第一关的战斗入口；本轮测试的是主动退出结算，不是整关胜利和完整奖励核验。全关卡进度、奖励到账、长期养成、所有活动及多人数据还待补齐。
5. **正式云端接入。** 创建独立服务账号、私有配置及角色持久目录，审核 systemd/Nginx 模板；先做私有回归，再启用 HTTPS 入口和游戏 TCP 端口。网站发布目录不参与此流程。
6. **生成云端 APK 并真机验收。** 用私有文件传入 HTTPS 地址，复用签名；测试移动网络、重连、关闭重开、存档和更新安装。当前后台是单个个人角色，尚非多账号服务。
7. **Android 16 兼容性。** APK `targetSdk=30`；原生库主要为 4KB 装载对齐，arm64 目录中另有两份 ELF32 库。模拟器实际以 arm64-v8a 运行成功，但 iQOO 11 的系统版本、页大小和所有库的加载情况仍需真机检查。
