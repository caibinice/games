# 向僵尸开炮 · 截图还原版

入口 `/games/zombie/`，另保留 `pc.html`、`mobile.html`。2026-10-23 第二版，按用户提供的6张1080×2400原版截图重建竖屏界面；商城、角色、核心、战斗为本轮开放范围。基地、军团、征途保留导航外观，点击说明尚未开放。不连接原作账号或服务器。

## 已接通的玩法

- **商城**：战术卡包、普通宝箱、高级宝箱；单抽、5连、10连、重复抽取，全部无限免费，无广告、无支付、无资源扣除。真实卡牌、宝石、装备入库；10 / 200次保底及概率说明。充值 / 特惠页为免费补给，金币、钻石、体力与材料可反复领取。
- **角色**：6件装备强化、升阶、品质替换；6部位×6词条×7品质宝石、每件5插槽、镶嵌 / 替换 / 卸下、锁定 / 筛选 / 3合1连锁合成。时装、佣兵、核心幻形选择有真实属性效果，非原作全套外观动画。枪械、先锋、机甲子入口目前提供对应已实现能力说明，并非原作完整子系统。
- **核心**：13种技能卡牌升级（1–100级），选择开局支援；5套方案独立保存出战技能与最多6个禁用技能。禁用技能排除出局内升级池。核心等级、装备、宝石与选择加成进入战斗计算。
- **战斗**：50关、5战区、每关20波、126–420名普通敌人；每5关精英、每10关首领，普通通关再开启加强的精英模式。真实自动射击、按住拖动集火、击杀经验三选一（技能最高5级）、两侧炮塔能量升级、空袭、伤害统计、1/1.5/2倍速、耐久条件宝箱、巡逻免费补给。
- 14项火力（步枪+13技能）：温压弹、干冰弹、高能射线、装甲车、制导激光、跃迁电子、冰爆、电磁穿刺、旋风、空投、气刃、燃油、无人机。装甲车+温压弹与旋风+电子有额外联动。
- P/Esc暂停、F全屏、Space空袭、1/2/3选升级。切后台/失焦自动暂停，弹窗焦点锁定。手机原生全屏及失败时沉浸布局，横握保留完整竖屏画面；iOS可添加到主屏幕。

## 结构与素材

`app.mjs`加载`original-app.mjs`；`screens.mjs`为DOM界面模板，`ui.css`以1080×2400设计坐标整体等比缩放；`progression.mjs`为养成纯逻辑，`engine.mjs`为可确定性模拟的战斗；`original-render.mjs`绘制战场，`profile.mjs`兼容旧进度，`audio.mjs`管理音频。旧`style.css`与`render.mjs`保留作第一版参考，不由新入口加载。

原截图场景和图标提供视觉底图，资源、等级、抽奖保底、背包和战斗HUD由真实DOM覆盖绘制，并非整张图上的空按钮。原图数量有限：僵尸采用电锯僵尸切片配色/尺寸变体，道路使用干净纹理拼接；部分动态数字区域、弹窗、帧动画和后续关卡地图不是原版逐像素/逐帧复现。音乐仍为已核实来源的CC0曲，不标为原声。来源与裁切坐标见[ASSETS.md](ASSETS.md)、[ORIGINAL_UI.md](ORIGINAL_UI.md)、[清单](ORIGINAL_UI_MANIFEST.json)。
