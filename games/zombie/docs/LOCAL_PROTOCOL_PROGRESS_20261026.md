## 已修正的关键点

1. **角色数据带分组存在标记。** `CSRoleData` 的 15 组应按原顺序写入标记及内容，缺失组不塞任意零字节块。
2. **空装备不是有效的已开启装备。** 首次发送开启但空 ID 的装备组，原生 `EquipDataMgr.CheckEquipCanUpLv` 查询空配置触发异常。当前暂不发送装备组，角色主页面及战斗可继续；装备完整实现单独列为待办。
3. **主页血量单位是百分数。** `LastMaxHpRate=1` 在 native UI 上显示 `1%`；满血对照值为 `100`，此时 native 显示“完美通关”。这是合成进度状态，不是本次已完成结算的证据。
4. **战斗入场必须单独通知。** 4252 只确认开始请求；真正的进入动作由 4253 驱动。
5. **战斗属性使用定点值。** `CSActorBattleAttrData` 的对应 long 属性采用 Q32.32，与主页浮点属性分开序列化。角色模型 11000/21000 来自原包默认男女模型配置。
6. **命令映射按分支执行核对。** 已用有界只读解释器核对实际分发表；早期线性静态扫描的结果未作为协议依据。
