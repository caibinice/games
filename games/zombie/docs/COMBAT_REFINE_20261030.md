# 战斗反馈、宝石洗练与寻星更新

版本：`20261030-combat-refine11`。本批改善战斗反馈和常用操作，并非完整 Unity 客户端移植。

## 本批修改

- 普通伤害和暴击均显示飘字，同目标短时间的普通命中合并，反馈不消耗战斗随机数。冻结状态下仍能看到受击闪白。
- 子弹碰撞增加定向命中火花，火、电、冰命中使用对应源贴图；枪焰跟随弹道方向，角色射击动作跟随实际连发时刻。
- 预加载 23 张 APK 特效贴图，补齐冰弹发射/命中、电磁范围与矩阵、旋风的环/光/主体分层。持续区域按自身出生时间播放，不再每次伤害 tick 叠加并重置整段动画。
- 角色背包增加“宝石洗练”按钮，可按六个装备部位筛选已拥有、可洗的宝石。锁定或已镶嵌的宝石需先解锁或卸下。
- 洗练使用已有源面板和直接替换流程，消耗 6/12/20 试剂，保持品质、部位和堆叠总数。材料不足时存档不变，刷新保留结果。
- 寻星领取七个大奖后立即开启下一轮，兼容旧存档已领满的状态；不重复发奖。网页补小星扫光、流星转移、月轮遍历及跳过设置。
- 统一入口缓存标记与游戏版本，避免仍显示旧查询串。

## 仍有差距

1. 使用源贴图不等于原生粒子系统一致；Unity 材质色彩、HDR、拖尾、完整粒子轨迹和镜头反馈仍需迁移。
2. 14 系技能的逐帧节奏、全部升级分支、伤害叠加与结算还需逐技能对照，当前浏览器实战不代表全部技能已验收。
3. 洗练结果遵守源品质/部位和消耗，原服随机权重未知，本地候选等概率；宝石选择列表仍是 H5 适配。
4. 其余活动家族、炫彩幻形/幻技、完整装备养成和全部 259 关结算仍按总清单推进，活动免费配置不代表原服当期概率。
