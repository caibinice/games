## 本批修复

### 装配白块与模型

白块不是中文缺字，而是缺失的 `zmzg_zb_zhuneng01/02` 装配状态图片。原 APK 未包含这两张图，现使用同包已有的亮/暗星形图片，并保留原生已装配/空槽判定。没有把测试截图放进游戏。

覆盖安装还暴露了缓存问题：Unity 会保留旧 IL2CPP 元数据。新版根据修改后元数据生成新的 `unity_app_guid`，让客户端重新提取元数据，不清除账号偏好。已在保留旧安装数据的模拟器中验证缓存更新和白块消失。

高级时装/核心在普通装配页没有模型，是普通分类缺少当前高级外观的指向。现在保留分类独立的拥有列表，同时给基础分类发送实际穿戴 ID；只拥有高级外观时也创建对应基础分类容器。原生高级核心模型、特效和装配页已正常显示。

另修了原包 `MechEffectParamConfig` 的表结构错配：该文件装了 7 条不符合运行库字段布局的记录，加载时触发断言并中断模型创建。现在使用有效空表，让引擎走已有的默认朝向分支，未伪造特效参数。当前 UI 与实战错误日志未再出现该断言。

### 缺少升级表的十个条目

原 APK 列出了五套时装及对应五个核心，却没有它们的升级表。为避免解锁后空引用、升星失败，UI 与战斗表各补 50 行；后台使用相同映射。
