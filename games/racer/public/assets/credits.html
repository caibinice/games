JET / R · 设计与素材

借鉴《天天飞车》的变道躲障与街机疾驰节奏，使用独立玩法代码和本地托管的三维素材。

  • 当前主车：用户指定的 3dSmartParking 项目现用车模。复用其双门 GT 外形、轮毂与贴图，并制作桌面 / 手机两档资源；车型未标为官方小米 SU7。该模型沿用原项目来源，不属于下列 Kenney CC0 素材。详细输入摘要与转换记录随源码的 xiaomi-assets.json / xiaomi-notes.md 提供。
  • 喷嘴、六种地图（草原 / 雪山 / 森林 / 城市 / 郊区 / 熔岩）、长挂车、限高门、道具与白色冷气粒子：本项目 Three.js 程序化构建。
  • 上一版 JET-R 原创概念车保留为编辑资源，不在正常游玩时加载；通过 Blender 4.5 LTS + Blender MCP 建模。
  • 交通车辆：Kenney Car Kit，CC0 公有领域。
  • 旧版引擎、轮胎与撞击音效资源（当前版本不加载）：Kenney Starter Kit Racing，CC0；轮胎音作者 Landeplage。
  • 旧版冷气喷流资源（当前版本不加载）：Kenney Sci-Fi Sounds，CC0。落地撞击：Kenney Impact Sounds，CC0。
  • 当前道具、氮气和飞跃音效：本项目原创短音，170–240 毫秒，在浏览器中预生成 Web Audio Buffer；无长尾刹车 / 引擎 / 撞击音效。
  • 背景乐：Fever Stadium · MintoDog，165 BPM Eurobeat，CC0 1.0，可循环播放，本站本地托管。它是独立曲目，并非《Rage your dream》原录音。
  • 喷气翻滚视觉参考：Tesla Roadster / 官方 Kickflip 演示。游戏不使用其商标或宣传素材。
运行时：Vue 3 · Vue Router · Three.js，开源许可见游戏大厅共享运行库。
