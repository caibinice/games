# 喷气飞车 3D · JET / R

Vue 3 + Three.js 的单人公路躲障游戏。借鉴天天飞车的变道、近距离超车、金币与 Combo 节奏，使用独立玩法代码和用户指定停车项目的现用 GT 跑车。

## 玩法

- 自动向前行驶，A / D 或方向键左右变道，手机点按左 / 右按钮。点击一次换一格，长按不连跳车道。手机按钮 96×90，紧凑横屏 86×80；按下即触发，一条车道约 73 ms。
- Space：冷气喷流腾空 → 360° 侧滚 → 自动扶正 → 缓冲落地。35% 能量、2.5 秒冷却、动作 1.65 秒；空中重复点击不会重置跳跃。
- Shift / N₂：点一下开启持续氮气，再点关闭。每秒消耗 14% 能量，耗尽自动关闭；普通行驶每秒恢复 8%，补给道具额外恢复 32%。
- 默认六格耐久，每 5 枚金币恢复 1 格，维修道具恢复 2 格。受击后短暂保护，车身保持可见、手机镜头不抖动。腾空可跨过小车和矮障碍；限高门从地面穿，22 米长挂车请左右绕行。
- 收集金币、贴近车流惊险超车、空中翻越可增加分数与 Combo。
- 30 关：草原 / 雪山 / 森林 / 城市 / 郊区 / 熔岩交替出现；8 类紧凑组合车阵、5 种编排，基础速度差不超过 3.4%，第一关就有挑战；另有无尽模式。
- P 暂停，F 全屏；手机开始后横屏全屏，支持方向与技能多指点按。喷气按钮有数字倒计时，重复点击会提示冷却或缺能量原因。
- 黑色魔鬼：7 秒左右颠倒，键盘和手机按钮同时生效；可避开不吃。
- 全速冲刺：8 秒免费强制加速，期间锁定氮气开关，结束后恢复普通速度。
- 隐身穿越：7 秒稳定透明发光（取消高频闪烁），忽略所有障碍（含长挂车），结束后有 0.65 秒缓冲。
- 车身修复：恢复 2 格，最多 6 格。
- 作弊按钮：无限喷气 / 氮气、无限耐久，自动保存；无限能量仍遵守 2.5 秒喷气 CD 和空中保护。无限耐久不扣血、不减速。辅助局与普通纪录分开，关闭辅助也不改变本局标记。
- 背景乐：MintoDog 的《Fever Stadium》，165 BPM Eurobeat（CC0）；开始后循环，暂停 / 后台停播；音乐与音效分别开关。
- 音效只保留道具、氮气开启和喷气三个原创短提示，分别约 170 / 200 / 240 ms；提前合成 Web Audio Buffer，不加载旧引擎、刹车、撞击、落地长音效。

组合车阵前后间隔 28–44 米，有三车道同时布置的‘穿门或飞跃’阵型；始终存在可操作的地面通路，在最高设计速度下也留有变道窗口。固定 60 Hz 模拟，按障碍真实长度做扫掠判定，已经通过的障碍不再产生延迟伤害。

## 存档

`jet-r-racer:pc:v1` 与 `jet-r-racer:mobile:v1` 独立保存关卡、模式、完成记录、普通 / 辅助最高分、作弊选项、车漆、音效与音乐偏好，保留旧存档兼容。刷新回到当前关起点，不保存半途车流。

## 源码与素材

- `public/engine.mjs`：确定性规则，米 / 秒单位，可直接在 Node 中运行。
- `public/tracks.mjs`：六种地图配色、八种组合和五种路线编排。
- `public/environment.mjs`：地图几何、树林、建筑、风车、火山与天气的实例化批次。
- `public/scene.mjs`：双端 GLB、交通车 / 长挂车 / 障碍实例化、道具池、阴影、冷气粒子、镜头与速度线。
- `public/audio.mjs` / `public/sounds.mjs`：独立 BGM 与三类原创短促提示，暂停静音、离开释放 Context。
- `public/presentation.mjs`：高刷新率单 tick 内视觉预测、稳定画布尺寸；物理碰撞仍固定 60 Hz。
- `web/src/pages/RacerPage.vue`：会话、响应式 HUD、选关、颜色、输入、自动存档与菜单。
- `art/build_car.py`、`art/jet-r.blend`：通过 Blender MCP 制作的原创模型脚本及可编辑工程。
- `art/xiaomi-build.mjs` / `xiaomi-assets.json` / `xiaomi-notes.md`：停车项目车模的只读转换、双端预算和来源记录；模型外观为双门 GT，未核验为小米 SU7。
- `art/asset-sources.json` / `art/audio-sources.json`：上游资源固定版本与校验信息。
- `public/assets/credits.html`：玩家可访问的署名与许可说明。

主车沿用用户指定停车项目来源，不归入 Kenney CC0 资源。手机车模约 1 MB、21,249 三角面、14 primitives，贴图基级 RGBA 估算 4.75 MiB；手机 DPR 上限 1.25，关闭动态阴影。交通车、道路、天气和背景使用实例化批次，粒子单批绘制；旧原创车仅保留资产，不在正常流程加载。研究截图仅用于构图参考。

全部车阵、道具、六种背景、透明材质变体在开始前创建 / 编译，并在加载阶段完成 GPU 资源上传；游戏中不等待新模型或材质编译。移除受击硬闪烁、手机镜头抖动和隐身高频闪烁。WebGL 上下文丢失时暂停，恢复后由玩家继续。

## 本地建模

本机已配置的 Blender 4.5 LTS 与 Blender MCP 路径及启动方式见 `docs/blender-local-setup.md`。通过 MCP 的 `execute_blender_code` 执行建模脚本，导出 GLB 后运行前端构建即可。Blender 仅用于离线资产制作，浏览器和服务器不依赖它。
