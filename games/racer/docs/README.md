# 喷气飞车 3D · JET / R

Vue 3 + Three.js 的单人公路躲障游戏。借鉴天天飞车的变道、近距离超车、金币与 Combo 节奏，使用独立原创代码和 JET-R 概念跑车。

## 玩法

- 自动向前行驶，A / D 或方向键左右变道。按住只切一条车道，松开后再次拨动可连续切换。
- Space：冷气喷流腾空 → 360° 侧滚 → 自动扶正 → 缓冲落地。35% 能量、5.5 秒冷却、动作 1.65 秒。
- Shift：按住氮气加速，持续消耗能量；能量会缓慢恢复，青色补给块额外恢复 28%。
- 三格车身，受击后 1.7 秒保护。腾空可跨过车流和矮障碍，避免撞上高横梁。
- 收集金币、贴近车流惊险超车、空中翻越可增加分数与 Combo。
- 30 关：蔚蓝海岸 / 落日都会 / 霓虹天际，各 10 关，路线距离、速度和车流密度逐步提高；另有无尽模式。
- P 暂停，F 全屏；手机采用左侧悬浮摇杆与右侧喷气 / 氮气按钮，支持多指并行。

每排始终留出可在地面通过的车道；固定 60 Hz 模拟，前后距离使用扫掠判定，已经通过的障碍不再产生延迟伤害。

## 存档

`jet-r-racer:pc:v1` 与 `jet-r-racer:mobile:v1` 独立保存关卡、模式、完成记录、最高分、车漆与声音偏好。刷新回到当前关起点，不保存半途车流。没有云同步或账号依赖。

## 源码与素材

- `public/engine.mjs`：确定性规则，米 / 秒单位，可直接在 Node 中运行。
- `public/scene.mjs`：本地 GLB、共享模型池、城市与车道线 InstancedMesh、阴影、冷气粒子、镜头与速度线。
- `public/audio.mjs`：引擎循环、滑胎、撞击、喷流与落地音效；卸载时释放。
- `web/src/pages/RacerPage.vue`：会话、响应式 HUD、选关、颜色、输入、自动存档与菜单。
- `art/build_car.py`、`art/jet-r.blend`：通过 Blender MCP 制作的原创模型脚本及可编辑工程。
- `art/asset-sources.json` / `art/audio-sources.json`：上游资源固定版本与校验信息。
- `public/assets/credits.html`：玩家可访问的署名与许可说明。

车辆为 Kenney CC0 交通模型和原创主角车，场景与效果为项目程序化创建。研究截图仅作构图参考，不作为游戏发行素材。具体网页、截图来源与喷气翻转官方参照见仓库研究文档。

## 本地建模

本机已配置的 Blender 4.5 LTS 与 Blender MCP 路径及启动方式见 `docs/blender-local-setup.md`。通过 MCP 的 `execute_blender_code` 执行建模脚本，导出 GLB 后运行前端构建即可。Blender 仅用于离线资产制作，浏览器和服务器不依赖它。
