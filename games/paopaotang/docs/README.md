# 泡泡堂 · 泡泡小镇

原创绘制的泡泡堂风格纯静态游戏，保留水泡、十字水柱、连锁、箱子道具、困泡与救援玩法。
不引用原作素材、账号或服务。单人对战 AI；PC 支持同一键盘的本地双人协作，非联网匹配。

## 入口

- 自动选择：https://caibinice.com/games/paopaotang/
- 电脑版：https://caibinice.com/games/paopaotang/pc.html
- 手机版：https://caibinice.com/games/paopaotang/mobile.html

PC 从 13×11 扩展至 17×15 格，手机从 11×11 扩展至 13×13 格，均有固定硬障碍、随机箱子和保证完整退路的出生区域。
共有 30 关、6 套主题（每主题 5 关）、5 位可选角色，轻松 / 经典 / 高手三种难度。

## 操作

| 玩家 | 移动 | 放水泡 | 救援针 |
| --- | --- | --- | --- |
| PC P1 | W A S D（单人也可用方向键） | Space | E |
| PC P2（双人协作） | 方向键 | Enter | Shift |
| 手机 P1 | 下方方向键，点按或按住 | 右侧水泡按钮 | 右侧救援针按钮 |

- PC 点击「全屏游玩」或按 F：按屏幕大小放大地图，隐藏装饰侧栏。F / Esc 退出全屏，不重开对局。
- P 或暂停按钮：暂停与继续；非全屏时 Esc 也可暂停。
- 离开页面、切换标签、打开说明和地图会暂停；刷新后暂停恢复当前棋盘，包括在场水泡与水柱。
- 改模式、难度、角色或重开，进行中的对局会先确认。已解锁地图、星星和最高分保留。

## 规则

- 水泡放在当前格，2.4 秒后向四个方向释放水柱。有效命中窗口 0.22 秒，水花视觉共 0.36 秒，淡出的尾部水花不再造成伤害。
- 硬障碍挡水；箱子被冲开并挡住本次水柱；碰到另一颗水泡立即连锁引爆。
- 放置者可以走出水泡格，水泡会挡路，走出后水泡格继续作为障碍。
- 初始最多 1 颗同时在场的水泡、水柱长度 2、速度 1、救援针 1。
- 箱子有概率掉落水泡数量、水柱长度、跑鞋、救援针或护盾；水柱退去后才可拾取。
- 能力上限：水泡 5、水柱 5、跑鞋 3、救援针 3、护盾 2。
- 水柱会把角色困进泡泡。4.5 秒内使用救援针可自救；协作时队友接触可免费救援；对手接触会立刻淘汰。
- 获救和护盾触发后有 1.4 秒保护，仍应及时离开水柱。水柱对敌友均有效。
- 消灭全部 AI 通关；人类队伍全灭或时间到则结束。双人模式一位淘汰后另一位可以继续。
- 轻松 / 经典 / 高手基础时间分别 210 / 180 / 150 秒，大地图自动增加时间，难度影响箱子密度、AI 移动速度与放泡积极性。
- 普通单人前 5 关为 2 位 AI，之后 3 位；高手单人始终 3 位；协作始终 2 位。

道具从 2 类（数量 / 长度）起步，每章逐步加入救援针、跑鞋、护盾，最多 5 类。后期箱子更密、AI 的水泡容量和水柱变强。

AI 规划水柱与连锁风险，确认退路后才放泡；会炸箱、追击、捡道具和救援同队 AI。
每次遇险只抽取一次失误判定：轻松 25%–34%、经典 18%–27%、高手 12%–21%，越后面的关卡越熟练。普通反应仍有 100–310ms 的观察过程，失误会迟疑至临近爆炸，保留真实命中机会；不会每 10ms 重抽。
每个出生点保证两步直行加转弯的安全走廊，避免初始水柱把角色封在角落。

## 分数和存档

人类水泡冲开箱子 +20，拾取道具 +30，AI 淘汰 +250，接触淘汰 AI 额外 +50。
胜利追加剩余整秒×5；全队存活且剩余超过 45 秒为三星，剩余超过 15 秒为二星，其他胜利一星。

存档只写 `fish-bubble-town:pc:v1` / `fish-bubble-town:mobile:v1`，两端独立。
地图解锁按模式与难度分别记录。v2 关卡存档严格校验新尺寸；v1 的旧尺寸、对局和星星原样保留，旧 125ms / 190ms 移动迁移时保留角色可见位置。第 12 关后可继续进入第 13 关。其他游戏存档、Cookie、资源和配置保持独立。
保存失败不影响当前对局；音效与轻音乐由 Web Audio 本地合成，没有媒体 CDN 或运行依赖。

## 源码和验证

- `tests/progression.test.mjs`：30 关、双端地图增长、道具种类、旧对局迁移、速度上限、失误统计与确定性回放。
- `tools/progression-smoke.mjs`：两款游戏 1 / 15 / 30 关选择、大地图全屏 / 手机布局、实际操作、续玩、末关和 12→13 解锁。

- `public/engine.mjs`：独立网格模拟，10ms 固定更新，运动、水泡、水柱、连锁、道具、AI、救援与存档。
- `public/renderer.mjs`：原创 Canvas 场景、角色、动画、水泡、水柱、道具和六套主题。
- `public/app.mjs`：双端控制、双人键盘、触屏、多点输入、暂停、关卡与本地存储。
- 按键、触屏和放泡立即处理；人类基础移动间隔 165ms，跑鞋等级 2 / 3 分别为 140 / 115ms，使用线性连续移动。短触转向有输入缓冲，键盘自动重复不抢占新转向。水柱按角色的可见位置判定。
- `public/fullscreen.mjs`：F / Esc 原生全屏及沉浸布局，棋盘按可用区域放大；浏览器未开放全屏 API 时保留同样的窗口内布局。
- `tests/latency.test.mjs`：8 项即时输入、线性移动、有效判定截止、无伤水花尾部和旧存档迁移回归。
- `tests/engine.test.mjs`：28 项规则 / AI / 存档测试，包含全部 180 种平台 / 难度 / 关卡组合的出生退路。
- `tools/browser-smoke.mjs`：供独立 Playwright CLI 会话运行的函数。它只重置该会话中的本游戏存档，通过可重复的标准规则棋盘验证键盘水泡通关、双人输入、免费救援、短触、自救、暂停、续玩和五种尺寸。
