# 果趣连连看 · Fruit Link

独立纯静态游戏，不引用拼豆、抓大鹅代码或资源，也不写它们的存档。

## 页面

- 自动选择：<https://caibinice.com/games/lianliankan/>
- PC 专属：<https://caibinice.com/games/lianliankan/pc.html>
- 手机专属：<https://caibinice.com/games/lianliankan/mobile.html>

入口根据触控设备或小屏选择页面，两端均保留手动切换入口。
PC 页面包含侧栏难度、关卡选择、快捷键；手机页面采用六列触控棋盘。

## 规则

1. 选择两颗相同水果，连线只经过空格，最多转弯两次。
2. 棋盘外有一圈可连通空间，允许从边缘绕行。
3. 清空棋盘过关，共 30 关、6 个章节、16 种原创 SVG 水果。
4. 每对基础 100 分；4 秒内连续配对形成连击，最多 5 连击、每对 200 分。无效配对清除连击。
5. 计时模式每次成功配对补充 2 秒，不超过本关初始时间；「自在慢玩」仅记录用时。
6. 每局 3 次提示、3 次洗牌、2 次加时（各 30 秒）；时间到后可使用剩余加时继续。
7. 没有可连对时免费自动洗牌，不扣除道具。

| 难度 | PC 棋盘 | 手机棋盘 | 初始倒计时 | 初始水果种类 |
| --- | --- | --- | --- | --- |
| 悠闲 | 10×6 | 6×6 | 240 秒 | 10 |
| 经典 | 10×8 | 6×8 | 180 秒 | 14 |
| 挑战 | 12×8 | 6×10 | 150 秒 | 16 |

后续每关减少 2 秒，最低 90 秒；每十关增加水果种类，最多 16 种。
通关用时不超过水果数×1.4 秒获得三星；不超过×2.8 秒获得二星，其他通关获得一星。
每种难度、模式独立解锁关卡，支持重玩已解锁关卡。

## 操作与存档

- 鼠标或触摸点选，重复点击同一颗取消选中。
- PC：方向键移动焦点，Enter 选中，Space 暂停/继续，H 提示，S 洗牌。
- PC：点击「全屏游玩」或按 F 放大棋盘、隐藏装饰侧栏；F / Esc 退出，保留本局状态。浏览器未开放原生全屏时使用窗口内沉浸布局。
- 页面隐藏、离开、打开说明/关卡/确认弹窗会暂停；刷新后以暂停状态恢复。
- 重开或切换难度/模式前确认；最高分、关卡星星保留。
- 存档只使用 `fish-lianliankan:pc:v1` 与 `fish-lianliankan:mobile:v1`，两端独立。
- 保存棋盘、倒计时、分数、道具、关卡及音效设置；存储不可用时仍能玩当前局。
- 音效由 Web Audio 合成，无外部媒体请求、广告或第三方运行依赖。

## 实现与测试

`public/engine.mjs` 使用带方向状态的 BFS 寻路，限制两次转弯。
生成器先按几何可连关系规划移除序列，再为每对分配水果，因而每张新盘和洗牌后棋盘都有可验证的完整解。
玩家选择其他移除顺序产生死局时自动洗牌；洗牌保留已清空格子和水果数量。

```powershell
npm run check
npm test
npm run build -- --games lianliankan
pwsh -File scripts/deploy.ps1 -Games lianliankan -SkipInstall
& .\.venv\Scripts\python.exe scripts/verify.py
```

`tests/engine.test.mjs` 覆盖直连、1/2/3 折、外圈绕行、300 张随机棋盘与独立枚举算法交叉校验、72 张可解棋盘、局部洗牌、计时、道具和存档损坏。
`tools/browser-smoke.mjs` 是供独立 Playwright CLI 测试会话运行的浏览器回归函数，重置**该测试会话**中的连连看存档，覆盖 PC/手机整局通关、道具、暂停、弹窗确认、续玩、加时复活、五种手机尺寸与键盘操作。

发布沿用共享单游戏原子流程：继承旧 release，仅替换 `games/lianliankan/`，更新大厅目录；其他游戏逐文件 SHA-256 核验。
现有 `/games/` Nginx 映射已经支持新子目录，不需要变更路由规则。
