# 赛车补给平衡与粒子视觉升级（2026-10-20）

## 规则
- 8 枚金币修复 1 格耐久，7 枚不触发；默认 6 格、维修箱 +2 格保持不变。
- 喷气跳跃统一消耗 20% 能量；恰好 20% 可起跳，低于 20% 提示缺能量。冷却仍为 2.5 秒，空中不连跳。
- 游戏、按钮状态、操作指南共用 `JET_COST` 常量。

## 道具与视觉
- 氮气：绿色带提手 / 油盖 / X 压纹的油桶。
- 黑色魔鬼：紫黑球头、双角和发光眼睛。
- 全速：金色闪电与小闪电。
- 隐身：冰蓝长水晶、斜环与小碎晶。
- 维修：红白医疗箱、提手和十字。
- 菜单与指南使用对应 SVG 轮廓，而不是五个相近的圆形徽章。
- 隐身替换为专用加法混合轮廓着色器：基底 alpha 0.006，边缘微光缓慢流动；取消实体车漆、投影和喷嘴，效果结束恢复原始车漆与玻璃材质。没有整车开关式闪烁。
- 氮气采用双喷口白芯、青蓝与紫色衰减拖尾：固定 TypedArray 池，手机最多 96 粒，PC 最多 160 粒，一次粒子批次绘制；停止加速后 0.34 秒内消散，暂停冻结，重新开局清空。
- 材质和几何资源开始前预热，未增加模型下载、贴图或第三方资源。

## 验证
- Vitest：455 项 / 26 文件通过，包含金币边界、跳跃能量边界、空中重复点击、粒子数量 / 数组复用 / 暂停 / 消散与隐身参数。
- 部署 Python 回归：10 项通过。
- 手机横屏 Chromium 模拟：方向键、大按钮、辅助开关、2.5 秒冷却、音效、持久化通过；1691 个运行帧样本 P95 7.1 ms，0 个超过 100 ms 的帧；资源数量稳定为 16 个程序 / 50 个几何体。这是工作站浏览器模拟结果，不代表实体手机帧率。
- 真实页面验证跳跃后约 80% 能量，粒子生效、换道响应及关闭后消散通过。
- PC 真实页面通过同一跳跃 / 粒子 / 换道回归：PC 粒子上限 160，开启阴影；手机上限 96，关闭实时阴影。
- 关闭全部辅助后，真实拾取恶魔、全速、隐身；隐身期间穿过障碍未掉血，7 秒结束后恢复正常车型，程序 / 几何体数量不增长。
- 独立可视化夹具检查五种道具、隐身与尾焰；夹具仅位于本地临时目录，不进入发布。
