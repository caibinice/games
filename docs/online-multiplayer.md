# 双人联机（2026-10-23）

## 入口与玩法
- `/games/tank/online.html`：黄 / 绿坦克双人合作，35 关共享基地、敌军与地形。
- `/games/contra/online.html`：独立移动、开火、跳跃、武器、死亡与重生；共享敌军、首领、摄影机与关卡。世界每 tick 只更新一次。通关后可继续下一关。
- `/games/paopaotang/online.html`：同队两名真人，与 AI 作战，独立水泡与针、被困和救援；通关后可继续下一关。
- `/games/lianliankan/online.html`：双方相同的 8×8 棋盘、12 种水果；每局 3 分钟。先清空获胜，超时比较剩余数量，相同则平局。
- 草莓 ❄ 冻结对手 2 秒，橙子 +4 补充最多两对并保证成对 / 可解，柠檬 ☁ 迷雾 4 秒。满盘时补牌转为迷雾；攻击有 2.5 秒限频。道具对双方对称。
- PC 两台设备均使用 WASD / 方向键、J 开火，魂斗罗 K / Space 跳跃。泡泡堂 J / Space 水泡、K / X 用针。
- 手机合作模式准备时进入横屏 / 原生全屏；浏览器未开放方向锁时使用旋转布局。左右悬浮摇杆与动作按钮支持触摸。连连看竖屏优先显示自己的大棋盘，对手缩略图实时同步，也可主动横屏。

## 房间与同步
- 快速匹配按游戏隔离，不跨游戏混配。好友房间为 6 位房间号，邀请链接不含玩家凭证。
- 双方准备，由 1P 房主开始。任何一方可共同暂停；重新准备后房主继续，保留当前战场。
- WebSocket 自动短线重连（最多 10 次、递增退避），掉线即暂停，避免无人控制角色继续送命。重连成功后重新就绪并继续。
- 房主浏览器以 60 Hz 运行共享模拟，状态约 20 Hz 同步；2P 输入按变化即时发送，短点按的开火 / 跳跃保留一个 tick，避免被快速松开覆盖。1.2 秒无输入心跳清空远端控制。
- 房主需要保持游戏页面前台；完整刷新页面不保留当前联机战场。房主离开会关闭房间。在线局不写入原单机存档或普通最高分。
- 坦克地图以占用格索引传输，典型战场帧约 6 KB；不传图片、音频或整张 Canvas。客端恢复地形遍历和动画外观，不重复推进世界物理。
- 此版本为休闲合作 / 好友对战，房主负责模拟；没有新增账号、积分排行或跨服务数据表。

## 后端与发布
后端位于 `E:/codes/enterprise-ai-cockpit/backend` 的 `com.example.aiagent.games`：
- `POST /smartCockpit/api/games/rooms`：create / match / join。
- `GET /smartCockpit/api/games/health`：联机模块健康检查。
- `wss://caibinice.com/smartCockpit/api/games/ws`：先在消息体鉴权，再使用 ready / start / input / action / frame / pause / resume / next / finish / leave / ping 消息。
- 使用独立 192-bit 随机玩家凭证，房间列表不返回凭证。最多 32 房间、2 人 / 房间；每连接最多缓存 4 条消息，消息大小 96 KB，限制发送频率和建房频率。
- 25 秒无消息关闭连接，房间过期清理；服务重启会清空临时房间，不修改座舱知识库 / 工作流 / 停车业务数据。
- 企业操作令牌仍保护原写接口，仅游戏命名空间采用独立能力凭证。
- 只在现有 Nginx 游戏片段增加精确 WebSocket 升级路由，复用 8080 内网端口，不开放新公网端口。
- 前端按选择只发布这四个游戏，其他游戏目录原样继承；座舱仅后端 JAR 原子发布，保留现有前端、环境文件和 systemd 单元。
