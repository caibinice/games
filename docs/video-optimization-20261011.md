- 新增暂存行立即切到末行，不再被遮住。屏高决定同时显示 1～3 行，上一 / 下一行连续翻页覆盖全部格子；无内层滚动条，不让游戏页向下增长。展示窗口不影响真实库存 / 总容量 / 一次放入量。
- 100 关 / 40 图、不规则轮廓与 v3/v4 存档协议不变。

## 手机一屏适配

游戏页原有最小高度和整页滚动是问题来源。现改为固定动态视口高度，中央场景 / 画板填充剩余空间，
全屏请求带 `navigationUI: 'hide'`，支持时锁竖屏；监听 visualViewport、窗口尺寸及 fullscreenchange。
游戏手势禁止文档平移 / 缩放，拼豆双指仍缩放画板。设置、图鉴等弹窗保留原生滚动。

高度采用动态视口与 visualViewport 的较小值，避免地址栏变化或全屏切换期间溢出。
参考 [MDN 动态视口长度](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length)、
[VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport) 及
[Chrome 视口调整说明](https://github.com/GoogleChrome/developer.chrome.com/blob/main/site/en/blog/viewport-resize-behavior/index.md)。
iQOO 11 官方规格为 1440×3200，属 20:9，故加入 360×800、393×873 等相同比例的 CSS 视口验证。
设备参数来源：[iQOO 11 规格](https://www.iqoo.com/in/products/param/iqoo11)。
