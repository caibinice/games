# 赛车手机手感、画面稳定与耐久辅助

## 改动

- 左右方向按钮从 66×65 放大至 **96×90**；短横屏从 59×58 放大至 **86×80**，触控面积约翻倍。按下立即触发，一次换一格；换道速度从 25 提至 44 m/s，一格约 73 ms。
- 默认 **6 格耐久**，每 5 枚金币修复 1 格，维修道具修复 2 格，最多 6 格；独立六格 HUD 在紧凑横屏同样显示。
- **喷气冷却 2.5 秒**，腾空动作 1.65 秒。重复空中点击不重置动作，不支持空中连跳；无限能量模式也保留冷却。
- 新增“作弊”菜单：无限喷气 / 氮气、无限耐久。碰撞不扣血、不减速；设置双端分别保存，辅助局不覆盖普通纪录。
- 音效仅保留道具、氮气开启、喷气三类原创短提示，约 **170 / 200 / 240 ms**，使用预合成 Web Audio Buffer；取消旧刹车、引擎、撞击和落地音效的加载与播放。背景乐继续保留独立开关。

## 画面与响应处理

1. 移除受击后每 85 ms 整车显隐切换，手机受击 / 落地不再摇镜头；隐身使用稳定透明发光，氮气尾焰去掉高频抖动。
2. 所有车阵和道具提前建池；六种背景、普通 / 透明材质提前编译，几何与贴图在加载界面完成 GPU 上传，行驶中无首次创建 / 编译停顿。
3. 全屏、音频硬件和新画布尺寸准备完成后，再启动比赛时钟，消除开始时把准备阶段计入游戏帧的卡顿。
4. 固定 60 Hz 碰撞模拟不变；90 / 120 Hz 屏幕使用不足一 tick 的视觉预测，平滑车身 / 相机 / 路面。画布尺寸按整数稳定比较，避免重复重置。
5. WebGL 上下文丢失时暂停并提示，恢复后由玩家继续；暂停时立即停止短音，保留静音音频上下文避免反复开启设备。

## 验证

- Vitest **450 项 / 25 个文件**，Python 发布测试 **10 项**，检查、生产构建和凭据审计通过。
- Chromium 手机模拟 DPR=3、844×390：左右按钮 96×90，触摸到首次绘制约 **18.9 ms**；连续 **1,675 个帧间隔**抽样，中位数 8 ms、P95 8.1 ms、最大 31.6 ms，超过 100 ms 的帧为 0。
- 运行中材质程序稳定 **19**、GPU 几何稳定 **48**，无新增编译 / 上传；全程车身可见，画布仅进入全屏时重置一次。该数据来自本机 Chromium 模拟，不作为实体手机帧率测量。
- 实际撞击耐久从 6 降为 5，再开启辅助后持续保持 6 格 / 100% 能量；喷气中再次点击未重置 CD，三次后续喷气按 2.5 秒间隔生效；刷新保留作弊偏好。
- 浏览器只请求 BGM，不再请求旧 engine / skid / impact / land / thruster 音效；实际短提示长度全部小于 241 ms。
- 为异步全屏 / 画布准备保留音乐手势解锁：在开始点击中预启动同一 BGM 元素，再进入比赛，符合 [WebKit 的媒体播放手势要求](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)。
- 390×844 窗口横屏降级、30 关菜单、氮气开关与数字冷却继续回归；规则测试覆盖金币修复一次性结算、加血上限、辅助关闭后的普通消耗与碰撞、v1 存档兼容。
- 568×320 方向键实测 86×80，作弊菜单完整落在视口内；原生全屏进入成功，主动触发 WebGL 上下文丢失 / 恢复后可暂停并正常继续。
