## 横屏策略

用户点击开始 / 全屏时优先请求浏览器全屏与 landscape 方向锁；方向锁未开放时，直接把整个游戏容器旋转为横向布局。摇杆输入反向映射到逻辑横屏坐标，动作按钮跟随旋转。真正横握后立即取消虚拟旋转。弹窗留在游戏容器内，不使用脱离旋转容器的 top-layer；因此关卡和辅助菜单同样可横屏操作。

浮动摇杆按下后跟随触点建立基座，死区避免误触；左右操作区独立 Pointer Capture，支持方向 + 开火 + 跳跃同时按住。pointercancel、失焦、暂停和卸载均清除输入。画布尽量占满可用高度，操作键放在左右留白处。
