# 抓大鹅：大轮廓、材质和深堆翻动优化（2026-10-11）

## 对比与改动

再次对照用户本机 `C:/Users/caibin/AppData/Local/UUYC/GameViewer/Download/1.mp4`、`2.mp4`。
上一版的圆球 / 方块比例、偏淡光照、宽口浅箱和低冲量，让物品看起来偏玩具、偏平铺。
本次只修改抓大鹅的表现与物理参数，拼豆源码、游戏库存、60 关目录和七格规则不变。

- **大而明确的轮廓**：重做玉米颗粒、长烤肠、五块烤串、宽肉排、面包片、弯香蕉、可颂、
  西瓜切片、带口沿和把手的杯子、瓶颈和瓶盖、牙刷、大鹅细颈和羽翼；同时改进苹果、
  草莓、鱼、贝壳和皮球。主要模型缩放由 1.34 调整到 1.65～1.78，镜头收紧，形状不是单纯放大圆球。
- **更接近实物的表面**：本地生成并复用 128×128 果皮、烘烤、肉纹、木纹与叶脉纹理。
  几何合批保留 UV；材质按果皮、肉、烘烤、陶瓷、塑料、金属区分粗糙度与光泽。
  加入本地环境光反射，降低泛白环境照明，保留接触阴影及侧面明暗。
  素材为程序化原创，不需要下载贴图或依赖外部 CDN。
- **深层堆叠**：普通箱内深度由约 4.1 增至 6.67 个世界单位，口宽收窄；5×5 起步、多层填充。
  长物和大鹅使用贴合主体的复合碰撞体，避免把细颈 / 把手 / 叶子之间的空气也当成实心大盒子。
  第一关保留浅教学箱；旧版稀疏存档单独适配。
- **真正翻锅**：0 / 190 / 410ms 三段冲量，包含同方向抛起、反向回甩与二次翻动。
  首次竖直速度增量 8.8～11，带正负角速度，减小阻尼；整堆刚体参与重力、碰撞与旋转，
  不是只加画布抖动。拖动方向会传入物理；容器辅以 720ms 大幅位移动效。
- **深箱收尾可操作**：剩余不足 48 件时，镜头逐渐转向俯看并聚焦底部，避免前沿挡住最后几件。
  不升高箱底、不摊平物品、不改 Cookie 里的身份或物理姿态。
- **保存不变**：v1 / v2 存档、已通关、暂放区、七格、续时保留；刷新即可应用新模型和物理表现，
  这次不需要重新开锅或清空 Cookie。旧存档原有数量继续保留。

技术依据：[Three.js MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)、
[DataTexture](https://threejs.org/docs/pages/DataTexture.html)、
[Cannon-es Body](https://pmndrs.github.io/cannon-es/docs/classes/Body.html)。
