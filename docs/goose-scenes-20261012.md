### 播放与设置

- 首次进入首页轻触画面或顶部 ♫ 启用音乐，开始游戏切换到游戏曲，回集市切回首页曲。遵循手机浏览器手势解锁，不在访问时提前请求音频或刷 autoplay 错误。
- 两个独立 PCM buffer 与暂停位置共用一个 AudioContext；先停止旧场景，再启用新场景，迟到的旧请求不会抢播。解码后循环，不在每轮重新请求或重建 source。
- 设置 / 暂停 / 胜利 / 超时弹窗与后台停音乐；恢复按当前场景续播。音乐开关仍与操作音效独立，首页多一个快捷按钮。
- 新增音乐音量 25%～100%，默认 90%，变化做 60ms 平滑。`goose_progress.musicVolume` 随原 Cookie 保存，旧静音偏好保留；关卡 / session 协议不变。
