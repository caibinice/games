# 坦克大战 / 魂斗罗：作弊与游玩辅助

日期：2026-10-16。只更新 `games/tank`、`games/contra` 和说明文档。保留 35 / 8 关与全部经典玩法。

## 实现

- 两款新增始终可访问的「作弊 / 辅助」菜单（快捷键 C），PC、手机、全屏均可用。菜单暂停模拟，原本在战斗时关闭自动继续；开关即时生效并随存档、选关、重开和续关保留。
- 坦克：无限坦克（死亡返还储备，基地仍需保护）、超级连发（75ms / 最多同时 8 发，仅玩家生效）、手动随机道具、每 8 秒自动随机道具。优先在身边可停留的空地生成，从六种原本道具抽选，仍需正常拾取，数量上限 6。
- 魂斗罗：无限生命、空中无限连跳（需松开再按，长按不自动连跳）、敌弹 55% 速度并高亮放大、无敌护盾。角色与己方子弹不减速；护盾不阻止掉坑，掉坑仍回安全点，无限命可避免扣命。
- 默认所有开关关闭。使用过辅助的本局保持 `assisted` 标记，单独保存 `assistedBest` / `assistedRecords`，不会覆盖经典成绩；关闭全部并重开后重新按经典计分。
- 原 v1 存档无需清理：保留关卡 / 对局与原成绩，缺失辅助字段迁移为全部关闭；既有 PC / 手机键不变。
